Shifa Network CIC website
=========================
A static website: no build step, no database, no server code.

Files
  index.html              The whole site (8 pages, switched with the menu)
  assets/logo.jpg         Shifa logo
  assets/favicon.svg      Browser tab icon
  assets/partners/        Partner logos
  robots.txt

Deploy (pick one)
  Netlify / Cloudflare Pages / Vercel: drag the shifa-website folder onto the dashboard.
  GitHub Pages: upload these files to a repository, then Settings > Pages.
  Normal web hosting: upload the folder contents to public_html (keep assets).
Preview locally: double-click index.html.

Update later (search index.html)
  "Coming soon"   Timetable, forms, bank transfer, extra classes
  Gallery         Placeholder tiles, replace with real photos
  Testimonials    Add stories (with permission)
Notes
  The contact form opens the visitor's email app addressed to info.shifawoking@gmail.com.
  Fonts load from Google Fonts, so an internet connection is needed to show them.
